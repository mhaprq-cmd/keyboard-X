
# Keyboard X

لوحة مفاتيح Android أصلية مبنية باستخدام Kotlin، مع تطبيق لإدارة الإعدادات واللغات والمظهر والدعم.

## حالة المشروع

- **الإصدار:** 0.1.0
- **المرحلة الحالية:** 7.1 — إعادة تصميم واجهة التطبيق.
- **منصة التطوير والبناء:** GitHub Actions.
- **حالة البناء:** نجح إجراء البناء الخاص بالتحديث الأخير.
- **اختبار الجهاز الفعلي:** لم يكتمل بعد.
- **حالة المرحلة 7.1:** قيد التحقق العملي، ولا تُعد مكتملة نهائيًا قبل اختبار التطبيق ولوحة المفاتيح على جهاز Android.

> نجاح البناء يعني أن المشروع اجتاز خطوات البناء والاختبارات التي شغّلها إجراء GitHub Actions. ولا يُعد ذلك بديلًا عن تجربة التطبيق على جهاز حقيقي.

## نبذة عن المشروع

Keyboard X مشروع تطبيق Android Native، وليس تطبيق ويب أو PWA مغلفًا داخل تطبيق Android.

يستخدم المشروع Kotlin وخدمة إدخال Android الأصلية (Input Method Editor - IME)، ويستهدف توفير تجربة كتابة بالعربية والإنجليزية مع واجهة تطبيق قابلة للتطوير تدريجيًا.

## الوظائف والواجهات الحالية

تتضمن بنية التطبيق وواجهته الحالية:

- صفحة رئيسية تعرض حالة لوحة المفاتيح وإجراءات تفعيلها واختيارها.
- قسم اللغات لاختيار اللغة المفضلة داخل التطبيق.
- قسم المظهر لإعدادات تخصيص الواجهة ولوحة المفاتيح.
- قسم الإعدادات، بما في ذلك خيار صوت ضغط المفاتيح.
- صفحات معلومات التطبيق والخصوصية وشروط الاستخدام والملكية الفكرية.
- صفحة المساعدة والدعم والأسئلة الشائعة.
- صفحة الإبلاغ عن مشكلة، مع التحقق من الحقول وتجهيز تقرير عبر تطبيق البريد الإلكتروني.
- واجهة تتبع تصميمًا بصريًا موحدًا يعتمد البطاقات والألوان المشتركة وموارد Android.

**ملاحظة:** وجود إعداد أو عنصر في الواجهة لا يعني بالضرورة أن كل وظيفة مرتبطة به مكتملة في خدمة لوحة المفاتيح. يجب التحقق من سلوك كل وظيفة أثناء الاختبار العملي.

## المرحلة الحالية: 7.1

تركز هذه المرحلة على إعادة تصميم واجهة تطبيق Keyboard X لتقترب من التصميم المرجعي المعتمد، مع الحفاظ على بنية لوحة المفاتيح الأصلية.

### ما تم إنجازه

- تحديث ملف `MainActivity.kt` وربط التنقل بين أقسام التطبيق.
- إضافة روابط صفحات المعلومات والدعم إلى قسم الإعدادات.
- ربط صفحة الدعم بخيار التواصل عبر البريد الإلكتروني.
- ربط خيار الإبلاغ عن مشكلة بواجهة `ReportIssueActivity`.
- نجاح إجراء GitHub Actions بعد التحديث الأخير.

### ما لم يُتحقق منه بعد

- تشغيل التطبيق على جهاز Android فعلي.
- اختبار جميع الصفحات والأزرار والتنقل والرجوع.
- اختبار تفعيل Keyboard X واختيارها كلوحة المفاتيح الافتراضية.
- اختبار الكتابة بالعربية والإنجليزية داخل تطبيقات أخرى.
- التحقق من أن إعدادات المظهر والصوت واللغة تؤثر فعليًا في الوظائف المقصودة.
- مراجعة العرض على أحجام الشاشات المختلفة وحالات الوضع الفاتح والداكن.

## البناء باستخدام GitHub Actions

يُستخدم GitHub Actions لتنفيذ البناء تلقائيًا عند الأحداث المحددة في ملفات سير العمل داخل المستودع.

لمراجعة نتيجة البناء:

1. افتح تبويب **Actions** في المستودع.
2. افتح أحدث عملية تشغيل.
3. تحقق من نجاح خطوات البناء والاختبارات.
4. إذا كان سير العمل يرفع APK كـ Artifact، افتح قسم Artifacts ونزّل ملف APK الناتج.
5. ثبّت النسخة على جهاز Android واختبرها قبل اعتبار المرحلة مكتملة.
