Keyboard X

لوحة مفاتيح Android أصلية مبنية باستخدام Kotlin، مع تطبيق لإدارة الإعدادات واللغات والمظهر والدعم.

حالة المشروع

- الإصدار: 0.1.0
- المرحلة الحالية: 7.3 — استكمال إعادة تصميم واجهة التطبيق.
- منصة التطوير والبناء: GitHub Actions.
- حالة البناء: اجتاز التحديث الأخير إجراء GitHub Actions بنجاح.
- اختبار الجهاز الفعلي: لم يكتمل بعد.
- حالة المرحلة 7.3: قيد التحقق العملي، ولا تُعد مكتملة نهائيًا قبل اختبار التطبيق ولوحة المفاتيح على جهاز Android.

«نجاح البناء لا يُعد بديلًا عن تجربة التطبيق على جهاز حقيقي، ولا يؤكد وحده عمل جميع الوظائف.»

نبذة عن المشروع

Keyboard X مشروع تطبيق Android Native، وليس تطبيق ويب أو PWA مغلفًا داخل تطبيق Android.

يستخدم المشروع Kotlin وخدمة إدخال Android الأصلية (Input Method Editor - IME)، ويستهدف توفير تجربة كتابة بالعربية والإنجليزية مع واجهة قابلة للتطوير تدريجيًا.

الوظائف والواجهات الحالية

تتضمن بنية التطبيق وواجهته الحالية:

- صفحة رئيسية لإجراءات تفعيل لوحة المفاتيح واختيارها.
- قسم اللغات.
- قسم المظهر.
- قسم الإعدادات.
- صفحات معلومات التطبيق والخصوصية وشروط الاستخدام والملكية الفكرية.
- صفحة المساعدة والدعم والأسئلة الشائعة.
- صفحة الإبلاغ عن مشكلة.
- واجهة تعتمد البطاقات والألوان وموارد Android.

وجود عنصر أو إعداد في الواجهة لا يعني بالضرورة أن الوظيفة المرتبطة به مكتملة أو تم التحقق منها عمليًا.

المرحلة الحالية: 7.3

تركز المرحلة على استكمال إعادة تصميم واجهة تطبيق Keyboard X، مع الحفاظ على بنية لوحة المفاتيح الأصلية.

ما تم إنجازه

- تحديث واجهة التطبيق وملف "activity_main.xml".
- الحفاظ على بنية المشروع الأصلية أثناء تحديث الواجهة.
- اجتياز إجراء GitHub Actions بعد آخر تحديث للواجهة.

ما لم يُتحقق منه بعد

- تشغيل التطبيق على جهاز Android فعلي.
- اختبار الصفحات والأزرار والتنقل والرجوع.
- اختبار تفعيل Keyboard X واختيارها كلوحة المفاتيح الافتراضية.
- اختبار الكتابة بالعربية والإنجليزية داخل تطبيقات أخرى.
- التحقق عمليًا من سلوك إعدادات الصوت والمظهر والخلفية.
- مراجعة العرض في الوضعين الفاتح والداكن وعلى أحجام الشاشات المختلفة.

سيتم التعامل مع الإصلاحات الوظيفية اللاحقة ضمن مراحل منفصلة، وفق نتائج اختبار التطبيق الفعلي، بدل جمع جميع التعديلات في مرحلة واحدة.

البناء باستخدام GitHub Actions

يُستخدم GitHub Actions لتنفيذ إجراءات البناء والاختبارات المحددة في ملفات سير العمل داخل المستودع.

لمراجعة نتيجة البناء:

1. افتح تبويب Actions في المستودع.
2. افتح أحدث عملية تشغيل.
3. تحقق من نجاح خطوات البناء والاختبارات.
4. إذا كان الإجراء يرفع ملف APK، افتح قسم Artifacts ونزّل الملف الناتج.
5. ثبّت النسخة على جهاز Android واختبرها قبل اعتماد المرحلة نهائيًا.

3. التحقق من نجاح إجراء GitHub Actions بعد التحديثات.
4. اختبار التطبيق فعليًا على جهاز Android.
5. تسجيل أي أخطاء أو اختلافات بصرية أو وظيفية.
6. توزيع الإصلاحات اللاحقة على مراحل منفصلة حسب نطاق كل إصلاح.
